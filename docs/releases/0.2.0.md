New look, more community favourites, and fixes.

## New
- **Logo:** the mxKeys keycaps ("mx" key with a yellow homing bar, then K E Y S) in the app and the README.
- **Left screen: picture under the battery.** The left half can now show a picture while keeping its battery and USB/Bluetooth icon, like the right half. (It covers the typing-speed graph, Bluetooth number and layer name.)
- **9 more community favourites (23 total):** Shift + Esc = ~, bracket pairs, one-shot layer, USB / Bluetooth switch, Bluetooth computer keys, media keys, bootloader combo, screenshot key, emoji key. The gallery now has category filters.

## Fixed
- Scrolling a long page (like Keymap) no longer drags the sidebar away and leaves empty space at the bottom.
- Keys that need an extra ZMK header (Bluetooth, USB/Bluetooth output, RGB, power) no longer break the firmware build: mxKeys adds the `#include` itself. Live editing understands them too.
- The "Hold for a layer, double-tap to lock it" favourite no longer picks a key for you (it could turn the key a conditional layer depends on into a lock). You choose the key, and it warns if the layer is part of a conditional layer.

## Install
| System | File |
|---|---|
| Windows | `mxKeys_0.2.0_x64-setup.exe` (or the `.msi`) |
| macOS (Apple Silicon) | `mxKeys_0.2.0_aarch64.dmg` |
| Linux | `.AppImage` (any distro) or `.deb` (Debian, Ubuntu) |
| NixOS | build from source: `nix-shell --run "cargo tauri build --no-bundle"` |

The app isn't code-signed yet:
- **Windows:** if SmartScreen warns, choose *More info → Run anyway*.
- **macOS:** if it says the app is damaged, move it to Applications and run `xattr -dr com.apple.quarantine /Applications/mxKeys.app`.
- **Linux:** make the AppImage executable (`chmod +x`).
