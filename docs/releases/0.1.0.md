First release of mxKeys: one app to set up, edit, build and install ZMK firmware.

## What's in it
- **Keyboard:** finds your keyboard, controller and screen from your config repo.
- **Keymap editor:** drawn from your keyboard's real layout. Layers, combos, macros and behaviors. Live editing over USB or Bluetooth (ZMK Studio).
- **Community favourites:** 14 proven tricks (home-row mods, Smart Shift, clipboard combos and more), each added as one Undo-able change.
- **Screen:** pictures for the nice!view, with drag, zoom and rotate.
- **Settings:** Bluetooth power, keyboard name, lights, screen and typing options.
- **Build & install:** builds the firmware on your computer (tools download by themselves) and installs it step by step. Commit and push to GitHub.

## Install
| System | File |
|---|---|
| Windows | `mxKeys_0.1.0_x64-setup.exe` (or the `.msi`) |
| macOS (Apple Silicon) | `mxKeys_0.1.0_aarch64.dmg` |
| Linux | `.AppImage` (any distro) or `.deb` (Debian, Ubuntu) |
| NixOS | build from source: `nix-shell --run "cargo tauri build --no-bundle"` |

The app isn't code-signed yet:
- **Windows:** if SmartScreen warns, choose *More info → Run anyway*.
- **macOS:** if it says the app is damaged, move it to Applications and run `xattr -dr com.apple.quarantine /Applications/mxKeys.app`.
- **Linux:** make the AppImage executable (`chmod +x`). If the keyboard isn't found over USB, the app shows the one-line fix for serial permissions.
